# 演示流程

以下为操作脚本，实际执行证据见 evidence/。演示数据为虚构数据。

1. 新建「CSV 汇总工具」，发送：开发一个无需依赖的 Python CSV 汇总工具，支持按分类计算金额总和。源码、测试和使用说明保存到 artifacts/，并运行测试。
2. 在执行记录中查看命令与结果，在文件与成果中预览源码、下载 ZIP。
3. 同一会话发送：增加 --json 输出选项，补充测试并运行。保留原来的 CSV 输出。
4. 新建「销售月度复盘」，上传 demo/sales.csv 和 demo/brief.txt，发送：核对材料，分析收入、成本、毛利以及环比变化，写出有依据的复盘和建议，保存 artifacts/report.md。
5. 执行期间切回代码会话，查看先前文件；刷新浏览器，确认历史与状态还在。
6. 回到报告会话，发送：追加不超过 150 字的管理层摘要，保留数据来源与局限。
7. 下载报告；关闭页面后重新打开，继续提问。

人工核对：9 月收入 70000，成本 39400，毛利 30600；10 月收入 78000，成本 42300，毛利 35700；收入环比 +11.43%，毛利环比 +16.67%。

异常演示：运行中点「停止任务」；服务重启后未完成任务显示「执行中断」；错误模型或额度不足显示真实 CLI 错误，修正配置后可继续发送。
